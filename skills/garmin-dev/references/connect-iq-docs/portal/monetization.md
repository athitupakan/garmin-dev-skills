# Connect IQ Monetization System

The Connect IQ™ monetization system gives developers the ability to monetize their Connect IQ apps. Customers are provided a straightforward purchase experience, and can create a single digital wallet that can be used for both Connect IQ content, as well as Garmin® products and services.
