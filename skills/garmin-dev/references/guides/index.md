# Guides

Task-oriented workflows. "How do I X?"

| File | Use when |
|---|---|
| [app-settings.md](app-settings.md) | User wants configurable colors / data fields / themes — "let the user change X". Covers the 3 mechanisms — Watch Face Configurations (system on-device editor, fēnix 8+/varies), App Settings (Properties, phone, all devices), and `getSettingsView` (on-watch menu you build, all devices) — and which to pick |
| [custom-fonts.md](custom-fonts.md) | Bundling a `.fnt` font via BMFont — Garmin built-in fonts aren't enough |
| [simulator-data.md](simulator-data.md) | Need to feed real-looking sensor data into the simulator (HR, body battery, stress, steps, battery, notifications, etc.) |
